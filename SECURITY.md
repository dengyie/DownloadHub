# Security Policy

## Supported Versions

Only the latest release on the default branch receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within DownloadHub, please do **NOT** open a public issue.

Instead, please report vulnerabilities privately by emailing the maintainer or using GitHub's Private Security Advisory reporting feature.

Please provide:
- A detailed description of the vulnerability.
- Steps to reproduce or a minimal proof of concept (PoC).
- The potential impact on systems running DownloadHub.

We take security seriously and will acknowledge your report within 48 hours and work on a fix promptly.
